TRANSPARÊNCIA

Privacidade e dados.

Esta página descreve o comportamento do código público desta aplicação. Não é uma garantia sobre logs de infraestrutura, serviços externos ou políticas de terceiros.

Consulta de IP

Para exibir o IP público, o navegador solicita dados da API ipify (api4.ipify.org e api6.ipify.org). O provedor dessa API recebe a conexão e pode processar dados técnicos conforme suas próprias políticas. O código desta ferramenta não envia esses IPs a um banco de dados próprio.

Consulta DNS

Quando você usa a consulta DNS, seu navegador envia o domínio informado ao endpoint DNS-over-HTTPS do Google Public DNS (dns.google). O Google poderá processar a consulta de acordo com suas políticas.

Calculadora CIDR

O cálculo de sub-redes é feito no navegador; o endereço digitado não é enviado a uma API pelo código da ferramenta.

Cookies, métricas e servidores

O código do aplicativo não configura cookies próprios, login ou analytics. A hospedagem e serviços de terceiros podem tratar dados técnicos e logs de acesso, fora do controle do código executado no navegador.

Uso responsável

Não compartilhe relatórios ou endereços privados de redes internas sem necessidade. Consulte também o repositório público para inspecionar o código.
